# Warehouse Control Room Demo

This demo renders a Google Maps–style, dark-mode warehouse visualization with live animations, KPIs, and activity logs. Open the `index.html` file via a simple static server to see the simulation.

## Running locally

From the repository root, start any static file server and open the served `index.html` in your browser. Examples:

```bash
# Python 3
python -m http.server 8000
# or, with Node
npx serve .
```

Then visit http://localhost:8000 in your browser.
